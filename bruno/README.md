# KOLEARA API Documentation with Bruno

Requirement :
- Bruno v3+, install [here](https://www.usebruno.com/)
- Jalankan server lokal dengan `pnpm run dev`

Setup :
- Buka Bruno
- Pilih :

```
Open Collection -> koleara/bruno -> select folder
```

- Pilih environment `local` (pojok kanan atas) sebelum mengirim request.
